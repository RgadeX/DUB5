# Icon Files

This directory should contain the following PNG files:

- `icon-192.png` - 192x192 pixel icon for PWA
- `icon-512.png` - 512x512 pixel icon for PWA  
- `icon-maskable-512.png` - 512x512 maskable icon for PWA

These icons need to be created manually or using an icon generator. The design should match the DUB5 brand with a star/game theme on the dark blue background (#0b1150).

For now, placeholder files are present which should be replaced with actual PNG icons.
